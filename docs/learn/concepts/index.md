## Learning Path

```
Nodes ──► Styles ──► Events ──► Components
```

Start with Nodes to understand the tree structure, then learn Styles for layout, and finally Events for interactivity.

## Quick Summary

| Concept | What It Does | Key Points |
|---------|--------------|------------|
| **Nodes** | Container for UI elements | Has style, children, optional ID |
| **Styles** | Layout and appearance | Flexbox-based, uses `Unit` for sizes |
| **Events** | User interaction | `on_click`, `on_change`, `on_focus` |
| **Components** | Pre-built elements | Button, Text, Slider, etc. |
