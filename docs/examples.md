# Examples

Example projects demonstrating arepy-ui features.

## Running Examples

```bash
cd arepy-ui
uv run examples/demo_components.py
```

## demo_components.py

Showcases all UI components: buttons, inputs, sliders, checkboxes, tabs, and more.

```bash
uv run examples/demo_components.py
```
