# Changelog

All notable changes to arepy-ui.

## [Unreleased]

### Added
- Complete documentation overhaul
- UIDebugger with F3-F6 shortcuts
- ColorPicker component
- AUI/ACSS markup system
- Global styles and theming
- Drag and drop components

### Changed
- Improved flexbox layout
- Better error messages

### Fixed
- Various layout edge cases

---

## [0.1.0] - Initial Release

### Added
- Core components: Node, Text, Button, Slider, Checkbox, Select
- Input components: TextInput
- Media components: Image, Video, Canvas
- Layout: ScrollView, Tabs
- Style system with flexbox
- Animation support
- UIManager for rendering

## Upgrade Guide

### From 0.x to 0.1

No breaking changes. Just update your dependency:

```bash
pip install --upgrade arepy-ui
```
